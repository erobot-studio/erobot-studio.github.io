How we teach

Build it. Program it. Teach it.

Every program follows the same spine, tuned to the robot and the age band.

Phase 1 · Build

Real screws, real servos

Students assemble their robot by hand — motors, wiring, cameras, batteries — and calibrate it. When it powers on, they know exactly why.

Phase 2 · Program

Python & computer vision

From driving the robot to handing control to code: scripted motion, camera vision with OpenCV, and autonomous behavior.

Phase 3 · Teach

Train it with real AI

Students record demonstrations and train neural network policies with LeRobot — the open-source stack from Hugging Face used in actual research labs.

Questions parents ask

FAQ

Does my kid need coding or robotics experience?

No. Every program starts hands-on with building and guided operation; programming is introduced with scaffolding that meets each student where they are. Students who already code get stretch goals every week — the max-4 class size makes real differentiation possible.

Is it safe?

Yes. Everything runs on low-voltage (5–12 V) electronics — the same safety class as toys and laptops. Students learn battery and tool discipline as part of the engineering habit, robots operate inside a taped arena, and instructors are background-checked.

Do we keep the robot?

Robots live at the studio — tuition covers instruction, not hardware, which keeps the programs accessible. Everything digital goes home: code, datasets, trained models, and the demo video. Families who want a home robot get a parts list and honest buying advice — it's all open source.

What if we miss a week?

With at most 4 students, we can usually schedule a short catch-up before the next session so nobody falls behind the build. Talk to us — the small cohort is exactly what makes this flexible.
