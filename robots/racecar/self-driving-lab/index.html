The 8-session journey

Every session, the car drives better than the session before.

Built on the open-source NVIDIA JetRacer curriculum — the same notebooks NVIDIA publishes for universities — extended with studio scaffolding and race engineering.

  • Session 1Build the car

    Assemble the JetRacer — chassis, camera mast, NVIDIA Jetson brain — and make the wheels move from Python in the browser.

  • Session 2Drive-by-wire

    Calibrate steering and throttle in software, race by gamepad, and learn the racing line the AI will later have to beat.

  • Session 3Label the racing line

    Build a real dataset by clicking where the car should aim on live camera images, then train a ResNet18 neural network and watch it learn.

  • Session 4First neural laps

    Connect the network's predictions to the steering. First fully autonomous laps — and a map of every place it fails.

  • Session 5Data is the new horsepower

    Fix the driver by fixing the data: targeted collection at failure spots, retrain, measure. The iteration loop real autonomy teams live in.

  • Session 6Need for speed: TensorRT

    Benchmark the model, optimize it with TensorRT for a measured multi× speedup, and spend the extra frames-per-second on throttle.

  • Session 7Race engineering

    Qualifying time trials, pit-stop retraining, one-variable-at-a-time tuning — then the race configuration is frozen.

  • Session 8Grand Prix — demo day

    Families watch autonomous time trials and head-to-head heats, while students present their data → training → optimization → deployment story.

Demo day

The Grand Prix: can the AI outdrive its makers?

In Session 2, every student posts a hand-driven lap time. On demo day their neural network races that same track — and most cohorts watch the AI beat its own teachers. Time trials, bracket heats, live commentary by the students, and a hands-on pit lane where parents label a camera frame and watch the car obey.

Program FAQ

About this program

What is JetRacer?

JetRacer is NVIDIA's open-source autonomous racecar: an RC chassis carrying a Jetson — the same family of AI computer that ships in real robots — and a fisheye camera. Students program it entirely from a web browser, and every line of the stack is public on GitHub, so what they learn here can be rebuilt and extended at home.

Does my teen need coding or AI experience?

No. The platform is browser-based Python notebooks, and every session starts from a working scaffold. Students who already code write the control and benchmarking code themselves from an API reference and take on weekly stretch goals — the max-4 class size makes real differentiation possible.

Is this real machine learning or a simulation of it?

Real. Students hand-label camera frames, train a ResNet18 convolutional network with PyTorch on the car's own GPU, diagnose its failures with data (not code), and optimize it with TensorRT — the identical toolchain used to deploy production robotics models. Nothing is canned: their car drives exactly as well as their dataset teaches it to.

Why ages 14–18?

This edition of the program is tuned for high schoolers: the training-and-iteration loop rewards patience and hypothesis-driven thinking, and the payoff — a resume-grade ML portfolio — matters most at college-application age. Younger engineers can start with LeKiwi (12–18, enrolling now) or Drone Explorers (8–11, coming soon).
