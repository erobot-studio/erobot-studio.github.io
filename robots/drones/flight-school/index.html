What to expect

The shape of the program

  • Python missions. Real code commanding real flight: waypoints, flying shapes, timing, and sensor-driven decisions.
  • Sensors & reactive autonomy. Range sensors and optical flow — how a drone knows where it is, and behaviors that react to a world it has never seen.
  • Engineering habits. Flight logs and live telemetry plots, pre-flight checklists, precision tuning, and debugging crashes like engineers.
  • Air Show finale. A scored autonomous obstacle-course run plus a choreographed routine, live for families.
