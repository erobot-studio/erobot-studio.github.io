What to expect

The shape of the program

  • Python missions. Real code commanding real flight: waypoints, timing, and sensor-driven decisions.
  • Sensors & autonomy. Range sensors and optical flow — how a drone knows where it is.
  • Engineering habits. Flight logs, pre-flight checklists, and debugging crashes like engineers.
  • Obstacle-course finale. An autonomous run through a course, scored live for families.
