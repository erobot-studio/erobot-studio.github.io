What to expect

The shape of the program

  • Build & puppet. Assemble and calibrate the follower arm, then teleoperate it through the leader arm — precision pick challenges from week two.
  • Python & vision. Joint control, saved poses, and an OpenCV-guided autonomous sorting cell that finds, grasps, and bins objects.
  • Research workflow. The record → train → evaluate imitation-learning loop used by actual robotics labs, on LeRobot — demonstrations published to the Hugging Face Hub for older students.
  • Portfolio finish. Trained model + GitHub repo + demo-day video, scored live for families — college-application material.
