What to expect

The shape of the program

  • Build & calibrate. Assemble the 6-joint arm from real servos; learn why calibration makes it trustworthy.
  • Teleoperate. Leader–follower control and precision pick challenges — cups, cubes, LEGO studs.
  • First Python. Scaffolded scripts: saved poses, scripted pick-and-place, and color-vision grabs.
  • Demo day. A tabletop sorting challenge run live for families.
