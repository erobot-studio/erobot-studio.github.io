# eRobot Studio — Logo Assets

The mark is the "e-Bot": the lowercase **e** of eRobot drawn as a robot face — two sensor eyes in the bowl, the crossbar as the mouth, one antenna with an orange tip.

## Files

| File | Use |
|---|---|
| `erobot-mark.svg` | Primary mark, ink on transparent — for light backgrounds |
| `erobot-mark-reverse.svg` | Cream on transparent — for dark backgrounds (navy `#141C28` / `#10151C`) |
| `erobot-lockup.svg` | Mark + "eRobot / STUDIO" wordmark, light backgrounds |
| `erobot-lockup-reverse.svg` | Lockup for dark backgrounds |
| `favicon.svg` | Heavier stroke weights tuned for 16–32 px |

## Brand colors

- Ink navy `#141C28` (dark ground `#10151C`)
- Warm cream `#F4F2EC`
- Signal orange `#E4570F` — antenna tip only; never recolor it
- Slate `#3E5A76` / `#9FB2C4` — secondary text

## Rules

- Keep clear space around the mark of at least the antenna's height.
- The antenna dot is always orange, in both color modes.
- The lockup wordmark uses system fonts (Avenir Next Condensed / Futura fallback). For print or non-Apple platforms, convert text to outlines before exporting.
